# Data staging (what must be present vs generated)

Paths below are **logical** names. On Gadi they resolve under `paths.data_root` / `paths.scratch_root` from your config YAML (see `config/gadi.example.yaml`).

## Must stage (not in git)

| Asset | Role | Notes |
| --- | --- | --- |
| FASTQs per cohort | Alignment inputs | Layout: `{fastq_dir}/{sample}_1.fastq.gz` + `_2` (Illumina) or `{sample}.fastq.gz` (long-read). Cohort dirs set in `config` → `cohorts.*.fastq_dir`. |
| `mpa4_res/merged_mpa.txt` | Species abundance filter for almost every script | **Required.** Build with MetaPhlAn4 (`jobs/gadi/03_metaphlan_array.pbs` + `04_merge_metaphlan.sh`). |
| kallisto abundances (`kallisto_res/`) | Expression groups / TPM plots | Needed for `plot_bias_vs_tpm.py`, `is_rna_analysis.py`, `hetero_vs_tpm.py`, `relaxed_aligner.py`. |
| NCBI / local archives for ARG & HYP | Replication cohorts | Sample IDs in `data/sample_lists/arg_samples`, `hyp_samples` — FASTQs are project-local (not full SRA manifests in-repo). |
| Kraken2 DB | MAG contig taxonomy | Set `software.kraken_db` / `$KRAKEN_DB` (replaces old `/groups/cgsd/hbyao/db/bfv/`). |
| Promotech install | Suppl. Fig. 1 | Set `software.promotech_home` / `$PROMOTECH_HOME`. |
| Optional: `assembly_summary_refseq.txt`, `names.dmp` | Live RefSeq lookup | **Not shipped.** Only needed if re-enabling dynamic RefSeq selection (currently pinned in `config/species_accessions.yaml`). |

### MetaPhlAn3 vs MetaPhlAn4 (honest gap)

- Analysis code expects **MetaPhlAn4** merged tables at `paths.mpa_merged` (historically `mpa4_res/merged_mpa.txt`).
- Repo ships **partial** `metaphlan3_res/` (ARG/HYP/Franzosa fragments + mock). This is **not** a drop-in for `mpa4_res/merged_mpa.txt`.
- Manuscript methods text historically said MetaPhlAn3; treat MPA version as a decision Gordon should confirm when regenerating abundance tables.

### Figshare shortcut (plot-only)

Precomputed species×sample TSS coverage matrices:  
https://figshare.com/projects/Metagenomic_coverage_bias_at_transcription_start_sites_is_correlated_with_gene_expression/242600  

Place extracted CSVs under `paths.matrices_dir`. Plot stages that need bigWigs/BAMs (null permutations, 5′, diversity, `--mp`, MAG) still require `beds/` / `bams/`.

## Generated by the pipeline

| Asset | Produced by |
| --- | --- |
| `refseq_genomes/{asm}/` (FNA, Prodigal GFF, filtered TSS, indexes) | `calc_coverage.py` → `prepare_species_folder` |
| `bams/`, `beds/*.bw`, `matrices/*.csv` | `calc_coverage.py` → `calc_cov` (BAMs preferred on **scratch**) |
| `plots/**` | `plot_heatmap_scatter.py`, `plot_bias_*.py`, mechanism scripts |
| `promotech_res/` | `compare_promoter_prediction.py` |
| `assembled_ref/` | `assembled_ref_bias.py` (assembly steps currently optional/commented) |
| `sketches/` | `containment_hashing.py` / sylph |
